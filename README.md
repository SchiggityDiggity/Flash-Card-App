# Flash-Card App created independently as practice creating an app with AI in course: Create your First App with AI

## Features:
Allows users to:
- Create a study deck
- Create 4 different types of studying cards (Flashcard, multiple choice, fill in the blank, True or False)
- Edit deck, delete deck
- View cards by format/types
- Study, allowing for certain types of cards or all formats
- Receive percentage/correct to incorrect after fully studying
- Add image for any flashcard from a file
- And more!

## How to use it:
- Opens in a browser page (You must clone it by getting the link and running it in VS code, or download index.html and open in)
- Create deck, add name for deck, create flashcards of any type/format
- Study and Recall anything and everything!
