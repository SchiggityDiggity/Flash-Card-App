Project: Flashcard App

Requirements:
- One self-contained index.html (HTML + CSS + JS in one file)
- Plain JavaScript only — no frameworks, no build step
- Store decks and scores in localStorage; never add a backend
- Clean card-style UI: big readable text, one question at a time
- Keyboard friendly: space flips the card, arrow keys navigate
- Allow users to create flashcards with a question and answer, image (optional), with the ability to edit and delete them.
- Allow users to organize flashcards into decks and view them in a list or grid format.
- Allow users to study flashcards in a quiz mode, where they can see the question and reveal the answer.
- Allow users to track their progress and performance on each deck, including the number of correct and incorrect answers.
- Allow users to study in different formats, such as multiple choice, true/false, and fill-in-the-blank.
- For multiple choice questions, allow users to create a question with multiple answer options and specify the correct answer.
- For fill-in-the-blank questions, allow users to create a question with a blank space and specify the correct answer, if answer is close enough to the correct answer, it should be marked as correct but provide feedback to the user that their answer was close.
- After implement or updating, run tests to ensure everything is working as expected, and show results from the tests in the console.
- Update Change_made_summary that contains each update/feature created, with a .md file that has a short summary of what was added/updated, with a more detailed assessment of the feature/change below the short summary.
